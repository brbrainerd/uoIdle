# ModernUO Ninjitsu Reference Mechanics: Clones, Stealth Openers, Delayed Detonation, and Forms

Source: [raw](../_raw/modernuo/NinjaSpell.cs)

## Summary

The canonical ModernUO Ninjitsu combat system combines illusory clone summoning ([[ninjitsu-mirror-image]]), shieldless melee precision strikes ([[ninjitsu-focus-attack]]), combat-hiding smoke bombs ([[ninjitsu-stealth-hiding]]), stealth-gated openers ([[ninjitsu-backstab]], [[ninjitsu-surprise-attack]]), stealth teleportation ([[ninjitsu-shadowjump]]), gap-closing distance strikes ([[ninjitsu-ki-attack]]), five-step delayed detonation marks ([[ninjitsu-death-strike]]), animal aspect transformations ([[ninjitsu-animal-form]]), and poison-capable throwing and blowgun weapons ([[ninjitsu-items]]). Unlike standard Magery spells, the shared NinjaSpell base class does not reveal hidden casters, does not clear equipped weapons from the caster's hands, and does not block movement while casting. Weapon combat hooks for clone diversion, defense-chance shred, and animal-form attack and poison bonuses execute inside the shared weapon combat loop documented in [[modernuo-bushido]].

## Shared `NinjaSpell` Casting Architecture (`NinjaSpell.cs`, **C1–C5**)

Every Ninjitsu spell (`MirrorImage`, `Shadowjump`, `AnimalForm`) inherits from `NinjaSpell`:
- **Stealth & Combat Preservation (**C1**):** `RevealOnCast => false`, `ClearHandsOnCast => false`, `ShowHandMovement => false`, and `BlocksMovement => false`, allowing a Ninja to cast while hidden, moving, and wielding melee weapons.
- **Expansion, Skill & Mana Validation (**C2–C4**):** Requires `Expansion.SE` (**C2**), checks `Caster.Skills[CastSkill].Value >= RequiredSkill` and `Caster.Mana >= ScaleMana(RequiredMana)` in both `CheckCast` (**C3**) and `CheckFizzle` (**C4**), and deducts `Caster.Mana -= mana` inside `CheckFizzle` (**C4**) while `GetMana() => 0` (**C5**).
- **Skill Check Window (**C5**):** `GetCastSkills` sets `min = RequiredSkill - 12.5` and `max = RequiredSkill + 37.5` (identical to `NinjaMove.CheckGain` in `[[ninjitsu-focus-attack]]`).
