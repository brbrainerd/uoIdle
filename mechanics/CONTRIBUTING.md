# Contributing to the UO Idle Mechanics KB

How any agent or developer adds, updates, or verifies a mechanics page in `mechanics/`. Only standard tools are required: `python3`, `node`, `gh`, `git`, `jq`, `rg`.

## 1. Read First

Before assuming any UO Idle mechanic, formula, cooldown, or class progression rule, read `mechanics/INDEX.md`, then the matching pages under `classes/`, `combat/`, `systems/`, `entities/`, `modernuo/`, and `topics/`. UO Idle (`https://uoidle.com/beta`) is a custom browser/server adaptation inspired by Ultima Online — never guess a formula or fill a gap from generic UO wikis without verifying against `mechanics/_raw/`. If the KB is silent, say so and treat the value as `unverified`.

## 2. Directory Layout

- `mechanics/_crawl/` — Gitignored staging cache for raw minified Vite JS bundles and unformatted downloads. Never commit anything from `_crawl/`.
- `mechanics/_raw/` — Immutable, deterministically formatted source files tracked in `mechanics/_raw/manifest.json` with SHA-256 and line-count provenance:
  - `_raw/bundle/` — Deterministically formatted (`prettier`, `printWidth: 100`) and AST-sliced (`acorn`) client bundle modules, JSON catalogs, and CSS rules from `https://uoidle.com/beta`.
  - `_raw/wiki/` — Official server and client changelog/compendium markdown extracts.
  - `_raw/api/` — Redacted API and WebSocket protocol registries.
  - `_raw/modernuo/` — Verbatim canonical C# source files from `modernuo/ModernUO` (`Bushido`, `Ninjitsu`, `HonorContext.cs`, `BaseWeapon.cs`, `SpecialMove.cs`, and Tokuno SE weapons).
- `mechanics/_evidence/` — Redacted live runtime, DOM, or network session excerpts cited via `live: _evidence/<file> L<a>-L<b>`.
- `mechanics/{classes,combat,systems,entities,modernuo}/<slug>.md` — Source-backed mechanics pages whose claims quote `sources[0]` verbatim via `(raw L<a>-L<b>)`.
- `mechanics/topics/<slug>.md` — Cross-cutting synthesis, structural parity, and simulator/design pages that may cite either `(raw L<a>-L<b>)` or `(evidence N)`.
- `mechanics/INDEX.md` — Generated by `python3 mechanics/tools/kb.py build --root mechanics`. Never edit `INDEX.md` by hand.

## 3. Frontmatter Contract

Every markdown page in `classes/`, `combat/`, `systems/`, `topics/`, `entities/`, and `modernuo/` must begin with nine keys in this exact order, one `key: <JSON literal>` per line between two `---` lines:

```yaml
---
id: "<slug>"
title: "<title>"
category: "<category>"
aliases: ["<alias>"]
status: "<tag>"
sources: ["_raw/bundle/<file>"]
evidence: []
code_refs: []
updated: "YYYY-MM-DD"
---
```

- `id` must equal the file stem (`<slug>`).
- `category` must be one of the **12 fixed UO Idle categories**:
  - `classes`
  - `skills`
  - `combat`
  - `status-effects`
  - `progression`
  - `items-equipment`
  - `dungeons-monsters`
  - `crafting-gathering`
  - `companions-mounts`
  - `engine-ui`
  - `modernuo-bushido`
  - `modernuo-ninjitsu`
- `aliases`, `sources`, `evidence`, and `code_refs` are JSON lists of strings (`["..."]`).
- `sources` are paths relative to `mechanics/` (e.g., `"_raw/bundle/classes-config.js"`, `"_raw/wiki/changelog-server-dev.md"`, `"_raw/modernuo/Confidence.cs"`). All `(raw L<a>-L<b>)` claims quote `sources[0]`.
- `code_refs` lists bundle identifiers, AST symbols, or design/schema references (e.g., `"Jogo-D5xEfvfV.js:gE"`, `"ModernUO:Spells.Bushido.Confidence"`).
- `updated` is an ISO date `YYYY-MM-DD`.

## 4. Evidence Rank Hierarchy

Six evidence tags, ordered **weakest first**:

```
contradicted < unverified < modernuo-stated < doc-stated < bundle-stated < verified
```

1. `contradicted` (rank 0): A live runtime measurement, server packet capture, or simulator verification disagrees with the stated claim.
2. `unverified` (rank 1): Neither bundle source, docs, nor live measurement backs the claim yet; a test recipe must exist under `## Test recipes` or `## Notes`.
3. `modernuo-stated` (rank 2): Quoted verbatim from canonical `modernuo/ModernUO` C# source under `_raw/modernuo/` as reference mechanics for Bushido/Ninjitsu/Parry/Perfection.
4. `doc-stated` (rank 3): Quoted verbatim from official server/client changelogs or wiki extracts under `_raw/wiki/`.
5. `bundle-stated` (rank 4): Quoted verbatim from the live UO Idle client bundle or static JSON packs under `_raw/bundle/` or `_raw/api/`.
6. `verified` (rank 5): Confirmed by a measured live runtime/network capture, DOM state snapshot, or calibrated simulator run (`network: `, `dom: `, `sim: `, or `live: `).

**Weakest-claim status rule:** A page's frontmatter `status` must equal the weakest claim tag present on the page (`min(tags, key=lambda t: RANK[t])`). If a page has no claims, its default `status` is derived from `sources[0]`: `modernuo-stated` when `sources[0]` starts with `_raw/modernuo/`, `doc-stated` when `sources[0]` starts with `_raw/wiki/`, and `bundle-stated` otherwise.

## 5. Claim Line Grammar & Digit-Free Summaries

```markdown
- **C<n>** [<tag>] "<verbatim quote>" (raw L<a>-L<b>)
- **C<n>** [<tag>] "<verbatim quote>" (raw L<a>)
- **C<n>** [<tag>] "<statement>" (evidence <N>)
```

- Every `(raw L<a>-L<b>)` or `(raw L<a>)` claim quote must appear **verbatim** (with whitespace and line breaks collapsed to single spaces) inside lines `a..b` (1-indexed, inclusive) of `sources[0]`.
- **Digit-free `## Summary` rule:** Numbers (`0-9`) are strictly forbidden inside the `## Summary` section (`summary-number` error). Every numeric constant, level tier, cooldown, mana cost, percentage, or formula term must live in a `- **C<n>**` claim under `## Claims`.
- **Cross-page links:** Use `[[slug]]` to link to any page across `classes/`, `combat/`, `systems/`, `topics/`, `entities/`, or `modernuo/`, and `[[slug]] C<n>` to cite a specific claim `C<n>` on that page. `kb.py check` enforces that both the target page (`link-broken`) and the target claim ID (`link-claim-missing`) exist.

## 6. Citing Evidence & Topic Synthesis Claims

Each entry in the frontmatter `evidence` array must begin with one of the **8 allowed prefixes**:

- `bundle: <slice>:<line or symbol>` — Cross-reference to a secondary bundle slice.
- `network: <endpoint or packet description>` — Measured HTTP API or WebSocket `[command` / `assunto` frame observation.
- `dom: <selector or UI state>` — Measured live DOM / React / Pinia / localStorage state from `uoidle.com/beta`.
- `wiki: <file>:<line>` — Cross-reference to an official changelog or compendium document.
- `modernuo: <file>:<line>` — Cross-reference to a canonical ModernUO C# source file.
- `sim: <script or run output>` — Deterministic combat simulator verification output.
- `code: <path>:<line>` — Project schema, simulator, or drop-in specification reference.
- `live: _evidence/<file> L<a>[-L<b>]` — Exact 1-indexed line span inside a committed, redacted file under `mechanics/_evidence/`. `kb.py check` verifies that `_evidence/<file>` exists and that `L<a>-L<b>` is within bounds (`live-bad-cite`).

### Rules for `(evidence N)` Claims

- `(evidence N)` claims (where `N` is the 1-based index into frontmatter `evidence`) are allowed **only on `topics/` pages**.
- Raw-only tags (`bundle-stated`, `doc-stated`, `modernuo-stated`) are forbidden on `(evidence N)` claims — if a statement comes from a raw file, quote `sources[0]` with `(raw L<a>-L<b>)` instead.
- Promoting an `(evidence N)` claim to `verified` or `contradicted` requires the cited `evidence[N-1]` entry to start with one of the **4 measured prefixes**: `network: `, `dom: `, `sim: `, or `live: `.

## 7. Credential Sanitization & Privacy Policy (`KB-01`)

- The GitHub repository (`https://github.com/brbrainerd/uoIdle`) must remain **PRIVATE** (`gh repo view brbrainerd/uoIdle --json isPrivate` must be `true`).
- Never commit raw browser dumps containing authentication secrets. Specifically, UO Idle stores guest and Google shard credentials and JWTs in `localStorage` under `uo-idle-token`, `uoidle.convidado`, `uoidle.google`, and `idToken`.
- `kb.py check` runs `check_credentials(root)` across all `.js`, `.json`, `.md`, `.txt`, `.cs`, and `.css` files in `_raw/`, `_evidence/`, and all page directories, failing with `credential-leak` if any of the following appear:
  - `Bearer <token>` headers (`Bearer\s+[A-Za-z0-9._~+/=-]{16,}`)
  - Raw JWTs (`eyJ[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}`)
  - `Cookie:` or `Set-Cookie:` headers with live values
  - Secret JSON fields (`uo-idle-token`, `idToken`, `password`, `access_token`, `refresh_token`, `client_secret`) whose values are not `<REDACTED>` or `REDACTED`
  - Unredacted email addresses outside `_raw/bundle/` and `_raw/modernuo/`

## 8. Extraction & Verification Workflow

```bash
# 1. Extract and slice live UO Idle v0.99.0 client bundle, changelogs, and API snapshots
node tools/bundle_extract.mjs

# 2. Fetch canonical ModernUO C# Bushido, Ninjitsu, Honor/Perfection, Parry, and SE weapon files
python3 tools/fetch_modernuo.py

# 3. Run the self-contained mutation self-test suite (28+ mutations)
python3 mechanics/tools/kb.py --self-test

# 4. Rebuild mechanics/INDEX.md and run full KB + manifest + credential verification
python3 mechanics/tools/kb.py build --root mechanics
python3 mechanics/tools/kb.py check --root mechanics
```

Both `--self-test` and `check --root mechanics` must output `"ok": true` and exit `0` before any commit.
