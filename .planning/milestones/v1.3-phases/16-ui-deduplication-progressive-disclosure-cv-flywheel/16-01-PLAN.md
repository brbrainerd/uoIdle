# Phase 16 Plan 01: UI De-duplication, Progressive Disclosure, Icon Geometry Fix, Interactive Progression Charts & Concept-Art CV Flywheel

## Objective
1. **Eliminate Repetition & Enforce Progressive Disclosure (`UI-DEDUP-01`, `UI-PROG-DISC-01`)**:
   - Replace the 3–4 stacked top toolbars across all 4 surfaces with a single beveled **Command Deck (`.command-deck`)** organized into semantic button clusters (`[Surface]`, `[Engine / Mode]`, `[Context / Bracket / Archetype / Locale]`, `[Section Jump / Kind Spotlight]`).
   - Refactor the 12 center **Milestone Ability Cards** on `samurai-skill-tree.html` and `ninja-skill-tree.html` into scannable Tier-1 cards (52×52 unclipped square icon, `L<N> · <Kind>` subtitle, Title, 1-sentence tactical summary, and 3 primary stat chips: `CD`, `Resource Cost`, `Primary Multiplier`), removing the duplicated 4-line lore walls, yellow Mode A/B paragraph boxes, and raw JSON drawers from the grid cards.
   - Refactor the right-hand **Deep-Dive Inspector** into a tabbed Tier-2 progressive-disclosure surface (`[Overview & Lore]`, `[Mode A/B Diff]`, `[Live 100ms Ticker]`, `[JSON Schema]`).
   - De-duplicate the Left Column (`Character & Resource Profile` + `Paperdoll & Armory`) so `STR/DEX/INT` bars, `2×4 Grandmaster Skill Pills`, the layered Paperdoll, 9-Tier Material selector, and single `Active Armament Card` appear cleanly without repeated class IDs or duplicate weapon stat blocks.
   - Refactor the Simulator (`class-comparison.html`) to match the approved Concept Art: 5 Hero Class Spotlight Cards with SVG sparklines & parity badges + a 2×2 Visual Telemetry Bento Grid (Interactive Progression Chart Deck, 5-Channel Breakdown, EHP/s Survival Curve, and an Interactive Tabbed Telemetry Drawer switching between `Live 100ms Rotation Timeline`, `5-Class Numeric Matrix`, and `9-Tier & 10-Wave Summary`).
2. **Fix Square Icons + Circular Icon Edge Cutoffs (`UI-ICON-GEOM-01`)**:
   - In circular medallions (`.arvore-circulo`, circular `.seal-medallion`), scale the inner `<img>` (`transform: scale(1.24)`) inside `overflow: hidden; border-radius: 50%` with an inset circular gold ring (`box-shadow: inset 0 0 0 2px var(--border-gold), inset 0 0 6px rgba(0,0,0,0.9)`) so the baked-in 5px square gold frame on `@64.png` icons is cropped cleanly outside the circle — zero straight square edges inside circles and zero corner cutoffs.
   - In square icon frames (`.milestone-icon-box`, `.dica-header`, `.arm-icon-box`), use a 2px-radius dark socket without clipping the 4 corner rivets of the painted square gold frame.
3. **Interactive Progression Chart Buttons & Direct SVG Clicks (`UI-PROG-CHART-01`)**:
   - On `class-comparison.html`: Add interactive Chart Metric buttons (`[Sustained DPS]`, `[Effective HP/s]`, `[Execute & Burst %]`, `[Parity Delta %]`), Class Curve Spotlight buttons, clickable SVG bracket columns/nodes (`L10`, `L25`, `L45`, `L60`), and a live `#chart-bracket-inspector` power-spike summary strip.
   - On `samurai-skill-tree.html` & `ninja-skill-tree.html`: Add interactive Progression Tier buttons (`[All L1–L60]`, `[Initiate L1–L15]`, `[Adept L20–L35]`, `[Grandmaster L40–L60]`, `[Step ▶]`) and a live `#cobra-live-summary` cumulative progression bar inside the `[Arvore` chart.
4. **Iterative Playwright + CV Flywheel (`UI-CONCEPT-CV-01`)**:
   - Rebuild all 4 pages, capture high-res screenshots, run `tools/audit_buttons_cv.ts` (expanded to test the new Progression Chart buttons, Inspector tabs, and Telemetry Drawer tabs), inspect captures inline with before/after comparisons, and iterate until 100% of checks pass and visual layout matches the approved concept art.
