# Plan 15-01: Smooth-Scroll Navigation, Sim Button Reactivity & Playwright + CV Before/After Audit

## Objective

1. Capture **BEFORE** screenshots and CV pixel/scroll telemetry via Playwright across all workbench pages (`mockups/class-comparison.html`, `mockups/samurai-skill-tree.html`, `mockups/ninja-skill-tree.html`, `index.html`) to document every button that currently uses show/hide (`display: none`), fails to scroll, or produces negligible visual/data change.
2. Replace all show/hide (`display: none`) behavior across all pages with **smooth section scrolling (`scrollIntoView`) + section/card spotlighting** so all sections remain visible at all times.
3. Make every button on the Simulator (`mockups/class-comparison.html`) and Skill Tree / Portal pages meaningfully update both the visual view and underlying telemetry:
   - **Workbench Section Navigation Buttons**: Smoothly scroll to each distinct section (`#sec-sim-controls`, `#sec-charts`, `#sec-endurance`, `#sec-matrix`, `#sec-armaments`, `#sec-weapons-affixes`) and apply `.is-focused-section` spotlight styling instead of hiding sections.
   - **Mode A vs Mode B Toggle**: Populate distinct `mode_a` and `mode_b` 5-channel damage breakdowns, EHP/s & mitigation curves, 10-wave endurance rows, and rotation logs so toggling Mode A/B visibly updates every chart and table on the Sim.
   - **Bracket (`L10`, `L25`, `L45`, `L60`) & Archetype (`low_def_boss`, `high_def_boss`, `fast_trash`, `multi_target_pack`) Buttons**: Dynamically update the active bracket indicator vertical marker & callout badge on both SVG Progression Charts, update the 5-Channel Breakdown bars, update the 20s Combat Rotation Log for that bracket/archetype, and update the 9-Tier Material Progression table for the active archetype (`lowDefBossDps`, `highDefBossDps`, `multiTargetDps`, `fastTrashDps`) with highlighted bracket row.
   - **Executive 5-Class KPI Cards, Quick-Dock Chips (`.kbd-chip`), Header Summary Cards (`.arvore-saldo`), Mastery Seals (`.passive-badge-item`), Cobra Nodes (`.arvore-col`), Hotbar Slots (`.hotbar-slot`), and Kind Spotlight Filters (`[data-kind-btn]`)**: Wire every interactive element to smooth-scroll to its target section/card and apply clear visual spotlighting without hiding content.
4. Capture **AFTER** screenshots via Playwright + screencapture and run Computer Vision (CV) before/after comparison (`tools/audit_buttons_cv.ts`) verifying that 100% of buttons produce measurable visual change (`diffPct > 0.5%` or `abs(scrollDeltaY) >= 40px`) with zero `display: none` section hiding.
