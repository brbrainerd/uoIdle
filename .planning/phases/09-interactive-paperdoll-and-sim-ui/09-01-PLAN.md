# Phase 9 Plan 01: Interactive Paperdoll with Gear Mouseovers & Simulator Visual Telemetry Dashboard

## Objective

Create the UI design contract (`09-UI-SPEC.md`) and upgrade `tools/build_mockups.ts` to build interactive Tokuno paperdoll armories with live mouseover gear stat cards on both class workbenches (`samurai-skill-tree.html` and `ninja-skill-tree.html`) and rich simulator visual telemetry charts on `class-comparison.html`.

## Tasks

1. **Task 1: Author `09-UI-SPEC.md` Design Contract**
   - Document color tokens, typography, interactive paperdoll layout (`3-column slot/canvas/slot grid` + `4-column weapon bar` + `9-tier material pill bar`), mouseover tooltip contract, and SVG chart specifications.
2. **Task 2: Upgrade `tools/build_mockups.ts` with Interactive Paperdoll & Visual Telemetry**
   - Add `PAPERDOLL_GEAR` registries for Samurai (6 Tokuno plate/lamellar armor slots + 4 iconic swords) and Ninja (6 cloth/leather shinobi slots + 4 assassin weapons) with 9-tier `Iron..Valorite` scaling math and bilingual (`en` / `pt-BR`) mouseover tooltips.
   - Add SVG multi-bracket DPS & EHP/s progression charts, 5-channel damage breakdown bars, 9-tier material scaling table, 10-wave dungeon endurance table, and 20-second `100ms` tick rotation log strips to `mockups/class-comparison.html`.
3. **Task 3: Build & CV-Audit Screenshots**
   - Run `npx tsx tools/build_mockups.ts && npm run verify:mockups` and inspect all rendered PNG screenshots with `read_file` to verify zero text overlap or clipping.
